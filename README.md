KredVouch

Skills • Experience • Trust

KredVouch is a platform designed to connect skilled workers with employers based on real skills, work experience, and trust.

The goal is simple:

Find skilled people. Trust their experience.

👷 For Workers

Workers can create a professional profile with:

* Full name
* Skills
* Other skills
* Job role
* Company / previous employer
* Work experience
* Current location
* District
* Work location
* Preferred location
* Languages
* Availability
* Phone number
* WhatsApp number
* Contact preference
* Verification information
* Portfolio

🏢 For Employers

Employers can:

* Search for skilled workers
* Filter workers by skill
* Filter by district
* View worker profiles
* Check work experience
* See verification information
* Contact workers by phone
* Contact workers through WhatsApp
* Connect with suitable workers

🔐 Technology

KredVouch is built using:

* HTML
* CSS
* JavaScript
* Supabase
* GitHub Pages

📱 Mobile First

KredVouch is designed with mobile users in mind, making it easy for workers and employers to use directly from their phones.

🎯 Vision

KredVouch aims to make skilled work easier to discover and trusted experience easier to verify.
